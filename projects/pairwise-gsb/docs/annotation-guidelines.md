# 生图 Pairwise GSB 标注规则（标注员执行版）本质

**提交前必须满足：**整体结论、三个分维度结论、归因标签和 reason 相互一致。任一维度错、标签漏选/错选、reason 与结论矛盾，整条均视为错误。

# 一、每条数据怎么标

每条数据包含 prompt、输入图/参考图（部分任务无）、生成图1和生成图2。标注时固定按以下顺序进行，禁止先凭整体观感选胜负，再反推分维度答案。

1. **读 prompt：**拆出必须完成的主体、动作、数量、位置、风格、色彩、文字、比例及保持要求。

2. **看输入图/参考图：**确认哪些内容用于编辑，哪些内容只用于参考，哪些内容未被要求改变。

3. **分别检查生成图1、生成图2：**先判指令遵循，再判一致性，最后判视觉效果。

4. **填写分维度 GSB：**每个维度独立选择“图片1更好 / 图片2更好 / 无法区分”。

5. **给较差图选择归因标签：**只选实际存在且造成该图劣势的问题，可多选，不得为凑标签而选。

6. **填写整体 GSB：**综合核心指令、问题数量、严重程度和视觉显著性判断。

7. **写 reason 并自检：**说明两图的具体差异，结论必须与所有字段一致。

# 二、GSB 结果怎么选

|结果|使用条件|
|---|---|
|**图片1更好**|图片1在该维度存在明确、可说明的优势，且差异足以影响判断。|
|**图片2更好**|图片2在该维度存在明确、可说明的优势，且差异足以影响判断。|
|**无法区分**|两图均无问题；两图存在相同或相近问题；或差异轻微、没有充分依据选边。无法区分是常见且正确的答案，不得为了“必须分胜负”而硬选。|

**整体 GSB 不等于分维度多数票。**核心指令未完成通常比轻微美观差异更严重；两图问题数相同时，再比较问题严重程度、画面占比和是否位于视觉中心。只有差异足够明确时才选边。

# 三、三个维度的硬边界

## （一）指令遵循

只看生成图是否完成 prompt 明确提出的要求，包括主体、动作、数量、位置、比例、文字、风格、色彩，以及 prompt 明确提出的保持要求。

**边界红线：**需要按对象分别判断。prompt 明确写了“保持 XX”“XX 不变”“保留 XX 特征”“保持原比例”等要求时，如果该对象未保持，属于**指令遵循**问题；与此同时，prompt 未要求编辑的其他区域仍需正常检查一致性，若人物、主体、背景、风格、色调等非编辑内容发生不合理变化，属于**一致性**问题。显式保持要求不等于整张图免做一致性判断，同一个具体问题原则上不在两个维度重复归因。

**指令遵循归因标签（必须使用标准名称）：**

- 世界/专业知识\-\-新概念/流行的/专有的新名词响应错误

- 世界/专业知识\-\-名人不像（非给定图，仅用于 T2I）

- 世界/专业知识\-\-场景类型错误

- 指令响应\-\-完全未响应

- 指令响应\-\-人像相关元素响应差

- 指令响应\-\-物体/图像等具象元素响应差

- 指令响应\-\-风格/色彩等抽象元素响应差

- 指令响应\-\-实体数量响应差

- 指令响应\-\-实体位置响应差

- 指令响应\-\-其他内容响应差

**标签选择补充：**真实人像的妆容、姿势、景别、性别、服饰、表情等选“人像相关元素”；动植物、道具、背景、图案、画幅比例等选“物体/图像等具象元素”；风格、色彩、滤镜等选“风格/色彩等抽象元素”。能使用具体标签时，不得用“其他内容响应差”兜底。

## （二）一致性

只用于有输入图/参考图的编辑任务，判断 prompt 未要求改变的内容是否被不合理改变。**文生图（T2I）不判一致性。**

**边界红线：**prompt 没有要求保持某内容，但输入图中的人物、IP、风格、色调、主体物或背景等本应稳定的内容发生改变，归为**一致性**问题。

**一致性归因标签：**

- 一致性\-\-知名IP保持差

- 一致性\-\-真人\-人物保持差

- 一致性\-\-非真实人物\-人物保持差

- 一致性\-\-风格/色调保持差

- 一致性\-\-其他元素保持差

**一致性比较口径：**优先看两图是否存在同类核心保持问题，不为轻微程度差硬选边。两图都有同类一致性问题、且差异不足以形成明确优劣时，判“无法区分”。如果一图有该类问题、另一图没有，可明确选边。

## （三）视觉效果

看生成结果本身是否结构正确、符合物理规律、自然真实、清晰、美观，并满足设计类场景的设计质量。视觉效果判断不能替代指令遵循：图更好看，但没有完成核心指令，仍需在指令遵循维度判差。

**视觉效果归因标签：**

- 视觉效果\-存在明显的结构崩坏

- 视觉效果\-结构无崩坏但违反物理规律

- 视觉效果\-自然真实\-生成效果不自然（假）

- 视觉效果\-自然真实\-AI感

- 视觉效果\-自然真实\-负向信息带入

- 视觉效果\-画质差

- 视觉效果\-基础美感差

- 视觉效果\-设计场景中设计感差

**AI 感豁免：**输入图本身 AI 感较强，且 prompt 未要求去除或改善 AI 感时，不标“AI感”。该标签重点用于真人场景，不得把所有不自然问题都归为 AI 感。

**美感与设计感的区别：**普通图片观感差选“基础美感差”；海报、Logo、流程图、产品平面设计等场景出现版式、层级、字体、配色、艺术风格或文字设计问题，选“设计场景中设计感差”。

## （四）任务类型与专项判断

**先确认任务类型，再判断一致性。**同样是“生成图与输入图不同”，在图片编辑和参考生成中的要求不同，不能使用同一标准。

|任务类型|判断重点|执行口径|
|---|---|---|
|**文生图（T2I）**|完成文字指令|无输入图，不判断一致性。只判断指令遵循和视觉效果。|
|**图片编辑**|完成编辑，同时保护非编辑区域|prompt 要求改变的区域按指令判断；未要求改变的区域原则上应保持稳定。人物、主体、背景、构图、色调或对比度发生明显无关变化，属于一致性问题。|
|**参考生成**|保持 prompt 指定的参考特征|只要求人脸、人物身份、IP、风格或其他指定参考特征保持一致，不要求生成图与参考图完全相同。不得把合理的重新生成误判为一致性问题。|

**水印等非主体信息：**水印、平台标签等信息被去除，通常可接受；但 prompt 明确要求保留时，应按指令遵循判断。

**文字内容专项判断：**

- **多字/少字：**prompt 明确给出文案时，遗漏或增加实质内容属于指令遵循问题；不影响原意的合理扩充不机械判错。

- **错字：**错别字、乱码、拼写错误属于指令遵循问题。

- **文字结构：**文字出现扭曲、残缺、重影、笔画粘连等，属于视觉效果问题。

- **文字属性：**prompt 明确要求颜色、大小、粗细等属性但未满足，属于指令遵循问题；prompt 未要求时，不得按个人偏好判错。

- **排版位置：**prompt 明确要求文字或图标的位置、对齐方式但未满足，属于指令遵循问题；无明确要求但排版明显混乱、影响阅读，属于视觉效果中的设计感问题。

- **特殊符号：**数学符号、线段、emoji、希腊字母等，只在确实存在漏响应、错误或结构崩坏时判问题。

**结构与物理规律：**多手指、少手指、肢体或物体连接错误、穿插粘连等可见形态错误，归“明显的结构崩坏”。非科幻设定且 prompt 未另行要求时，一只手或脚以 5 个指头为常规标准。结构本身完整，但悬浮、反射、重力、比例或运动状态违反常识，归“结构无崩坏但违反物理规律”。

**拉伸与比例：**生成图出现明显拉伸、压缩，导致人物、主体物或场景元素形变，归视觉效果问题；如果 prompt 明确要求画幅比例却未满足，同时属于指令遵循问题。两个问题确实同时存在时，应分别说明，不得只写“比例不对”。

**清晰度与画质：**图片编辑任务中，生成图相较输入图出现明显模糊、噪点、马赛克或清晰度下降，归“画质差”；属于合理的正向优化时不判问题。T2I 中即使没有输入图，只要成图存在肉眼明显的模糊或低清，也可判“画质差”。

**色调、亮度与对比度：**图片编辑任务中，未被要求改变的色调、亮度或对比度发生肉眼可见的明显变化，归一致性问题；prompt 明确要求调整但未完成，归指令遵循问题。仅在放大后才能发现、且不影响主体的轻微变化，不作为硬选边依据。

# 四、整体结果的判断顺序

1. **先看核心指令：**一图未完成核心任务，另一图完成，通常完成的一图更好。

2. **再看问题数量：**常规情况下，明确问题更少的一图更好。

3. **问题数量相同时看严重程度：**主体错误、核心内容错误、明显结构崩坏，通常高于边缘区域的小瑕疵。

4. **严重程度接近时看视觉显著性：**问题越靠近视觉中心、画面占比越大、越影响主要内容，越严重。

5. **仍无充分差异则判无法区分：**不得凭个人偏好、审美风格或“看起来稍微顺眼”硬选。

# 五、归因标签填写规则

- 归因标签按任务字段要求填写，但 reason 的问题暴露不受胜负限制：**胜出图有显著问题也要写，两图存在共性问题也要分别或合并说明。“无法区分”时，不得随意给单边加归因制造胜负。**

- 一张图存在多个独立问题时可多选，不能只选最显眼的一个而漏掉其他明确问题。

- 禁止因同一事实在多个维度重复打标；**若同一对象存在多个独立问题（如保持失败与视觉质量差），应分别归入对应维度。**

    - **🌰举个例子：**

    Prompt：保持沙发颜色不变。

    输出图：**沙发由蓝色变成绿色**/**新绿色颜色脏、明度不协调。**

    应该标：

    > 1. **指令遵循：未完成保持颜色要求。（因为 prompt 明确要求保持）**
    > 
    > 2. **视觉效果：颜色搭配不协调。**
    > 
    > 

- 标签必须与 reason 中描述的问题一致；reason 写了明确问题但未选对应标签，视为漏标。

- 能使用具体标签时，不得用“其他”类标签替代。

# 六、reason 写法

**reason 的作用是客观暴露问题，并让质检人员仅看文字就能复核结论。**两张图中所有肉眼可见、可确认的显著问题都必须说明，无论该图最终胜出还是落败；两图共有的问题也必须写清。必须写具体对象、具体位置、具体问题、两图差异和最终结论，禁止只写“图1更好”“存在一致性问题”“视觉效果较差”。不得为了支持胜负结论而只描述落败图的问题，也不得编造无法确认的轻微问题。

**推荐格式：**

> 指令遵循：图1……；图2……。
> 一致性：图1……；图2……；T2I 写“不涉及”。
> 视觉效果：图1……；图2……。
> 综合判断：由于……，因此图片1更好 / 图片2更好 / 无法区分。
> 
> 

**合格示例：**指令遵循上，两图均完成“给人物换上参考服装”的核心要求。图1眼镜未保持、人物脸型有轻微变化；图2人脸也有变化，且左下角人体被遮挡并出现明显结构崩坏。两图均存在人物一致性问题，但图2额外存在位于显著区域的结构问题。综合来看，图片1更好。

**不合格示例：**图1整体更自然，图2有问题，所以图1更好。

# 七、禁止事项

- 禁止先选整体结果，再把三个分维度全部机械填成同一结果。

- 禁止因担心选“无法区分”而强行分胜负。

- 禁止把 prompt 明确提出的保持要求误判为一致性。

- 禁止在 T2I 任务中判断一致性或填写一致性归因。

- 禁止根据个人喜好的画风、颜色、人物长相决定胜负。

- 禁止复制模板后不修改具体对象和问题。

- 禁止 reason 与 GSB 结论、归因标签相互矛盾。

# 八、提交前逐条自检

* [ ] 我已完整阅读 prompt，并拆出所有明确要求。

* [ ] 我已确认任务是否为 T2I，以及是否需要判断一致性。

* [ ] 我没有把 prompt 明确的保持要求错归为一致性。

* [ ] 三个分维度均独立判断，没有跟随整体结果机械选边。

* [ ] 无法形成明确优劣时，我选择了“无法区分”。

* [ ] 所有明确问题均选择了准确的归因标签，没有漏标、错标或重复归因。

* [ ] reason 已写清两图所有可确认的显著问题，包括胜出图的问题和两图共性问题，并注明具体对象、位置、差异及最终结论。

* [ ] 整体结果、分维度结果、归因标签和 reason 完全一致。

# 九、退回标准

出现以下任一情况，整条退回：整体或任一分维度结论错误；指令遵循与一致性边界判错；应判“无法区分”却无依据硬选边；归因标签漏选、错选或重复归因；reason 漏掉任一方的显著问题或两图共性问题；只描述落败图、没有客观说明胜出图问题；问题描述笼统，未写具体对象或位置；reason 模板化、与字段或最终结论矛盾；T2I 错判一致性；触发 AI 感豁免却仍标 AI 感。

遇到规则未覆盖或无法确认的 case，不得自行扩展口径，应先提交疑难 case，待统一口径后再继续标注。
