# GSB 标注员（AI Agent 执行版）

对生图任务进行 Pairwise GSB（Good/Same/Bad）标注，对每组（prompt + 图片1 + 图片2）输出完整标注结果。

## 前置确认

调用前需确认：
- **数据文件路径**：Excel 或 JSON，包含 prompt、图片1、图片2
- **输出文件路径**：标注结果写入位置
- **标注范围**：全部 or 指定行号

## 输入字段

| 字段 | 说明 |
|------|------|
| `prompt_cn` | 中文 prompt |
| `输入图1/2` | 参考图/输入图（编辑任务有，T2I 为空） |
| `图片1` | 待标注生成图 1（URL 或路径） |
| `图片2` | 待标注生成图 2（URL 或路径） |
| `难度` | 仅参考，不影响标注 |
| `本题难点` | 仅参考，提示该题风险点 |

## 输出字段（需要填写）

| 字段 | 可选值 | 说明 |
|------|--------|------|
| `整体gsb结果` | `图片1更好` / `图片2更好` / `无法区分` | 综合判定 |
| `分维度gsb/指令遵循` | `图片1更好` / `图片2更好` / `无法区分` | 只看 prompt 明确要求的完成度 |
| `分维度gsb/指令遵循归因标签` | 见下方标签表 | 多选用 `、` 分隔 |
| `分维度gsb/一致性` | `图片1更好` / `图片2更好` / `无法区分` | T2I 填 `不涉及` |
| `分维度gsb/一致性归因标签` | 见下方标签表 | T2I 填空 |
| `分维度gsb/视觉效果` | `图片1更好` / `图片2更好` / `无法区分` | 结构/物理/自然度/画质/美感 |
| `分维度gsb/视觉效果归因标签` | 见下方标签表 | 多选用 `、` 分隔 |
| `reason` | 结构化文本 | 两图问题 + 差异 + 结论 |
| `评测人` | 字符串 | 标注者标识 |

## Procedure

### Step 1：读取输入

读取 Excel 中的 prompt、输入图/参考图、图片1、图片2。图片无法直接查看时，基于 prompt 做预分析。

### Step 2：确定任务类型

| 条件 | 任务类型 | 一致性维度 |
|------|----------|------------|
| 无输入图/参考图 | **文生图（T2I）** | 不涉及，不判断一致性 |
| 有输入图，prompt 含"编辑/修改/替换/去掉/加上"等 | **图片编辑** | 必须判断 |
| 有参考图，prompt 含"参考/风格/类似"等 | **参考生成** | 仅判断指定参考特征 |

### Step 3：拆解 prompt

按以下维度拆出所有硬约束：
- **主体**：人物/动物/物体/场景
- **动作/姿态**：做什么、姿势
- **数量**：几个、多少
- **位置**：在哪里、空间关系
- **文字**：具体文案、字体要求
- **风格/色彩**：画风、色调、滤镜
- **保持要求**：prompt 明确写"保持 XX""XX 不变""保留 XX"

### Step 4：逐图检查（先图1后图2）

对每张图检查：
1. **指令遵循**：prompt 的每个明确要求是否完成
2. **一致性**（仅编辑/参考任务）：未要求改变的内容是否被不合理改变
3. **视觉效果**：结构、物理、自然度、画质、美感

### Step 5：填写分维度 GSB

每个维度独立判断：
- 一图有明确优势 → 选该图更好
- 两图均无问题 或 问题相近 或 差异轻微 → `无法区分`

**关键：**指令遵循优先于视觉效果。核心指令未完成 > 轻微美观差异。

### Step 6：选择归因标签

只在较差图实际存在的问题上打标。一张图多个问题可多选。禁止凑标签。

### Step 7：填写整体 GSB

判断顺序：
1. 核心指令完成情况（权重最高）
2. 问题数量
3. 问题严重程度
4. 视觉显著性（是否在视觉中心/画面占比）
5. 仍无充分差异 → `无法区分`

### Step 8：写 reason

格式：

```
指令遵循：图1……；图2……。
一致性：图1……；图2……。（T2I 写"不涉及"）
视觉效果：图1……；图2……。
综合判断：由于……，因此图片1更好/图片2更好/无法区分。
```

**强制要求：**
- 两图的所有显著问题都必须写，包括胜出图的问题
- 两图共性问题必须说明
- 写具体对象、具体位置、具体问题
- 禁止只写"图1更好""存在一致性问题"

### Step 9：自检一致性

- [ ] 整体 GSB、三个分维度 GSB、归因标签、reason 相互一致
- [ ] T2I 任务一致性已写"不涉及"
- [ ] prompt 的保持要求未错归为一致性
- [ ] 未硬选边（差异化不明确时应选"无法区分"）
- [ ] reason 暴露了两图的所有问题

## 归因标签速查

### 指令遵循

| 标签 | 适用场景 |
|------|----------|
| 世界/专业知识--新概念/流行的/专有的新名词响应错误 | 专有名词、流行概念生成错误 |
| 世界/专业知识--名人不像（非给定图，仅用于 T2I） | T2I 名人不相似 |
| 世界/专业知识--场景类型错误 | 场景类别错误 |
| 指令响应--完全未响应 | 完全忽略指令 |
| 指令响应--人像相关元素响应差 | 妆容/姿势/景别/性别/服饰/表情 |
| 指令响应--物体/图像等具象元素响应差 | 动植物/道具/背景/图案/画幅 |
| 指令响应--风格/色彩等抽象元素响应差 | 风格/色彩/滤镜 |
| 指令响应--实体数量响应差 | 数量不对 |
| 指令响应--实体位置响应差 | 位置不对 |
| 指令响应--其他内容响应差 | 兜底，能不用就不用 |

### 一致性

| 标签 | 适用场景 |
|------|----------|
| 一致性--知名IP保持差 | IP 形象变化 |
| 一致性--真人-人物保持差 | 真实人物特征变化 |
| 一致性--非真实人物-人物保持差 | 虚拟/动画人物变化 |
| 一致性--风格/色调保持差 | 风格或色调变化 |
| 一致性--其他元素保持差 | 其他元素变化 |

### 视觉效果

| 标签 | 适用场景 |
|------|----------|
| 视觉效果-存在明显的结构崩坏 | 肢体错位/多手指/少手指/穿插粘连 |
| 视觉效果-结构无崩坏但违反物理规律 | 悬浮/重力/反射/比例/运动异常 |
| 视觉效果-自然真实-生成效果不自然（假） | 看起来假、不真实 |
| 视觉效果-自然真实-AI感 | 真人场景 AI 感（输入图本身 AI 感强则豁免） |
| 视觉效果-自然真实-负向信息带入 | 不适当的负面内容 |
| 视觉效果-画质差 | 模糊/噪点/马赛克/清晰度下降 |
| 视觉效果-基础美感差 | 普通图片观感差 |
| 视觉效果-设计场景中设计感差 | 海报/Logo/流程图等版式/配色/字体问题 |

## 特殊判断规则

### 文字内容
- **多字/少字**：遗漏/增加实质内容 → 指令遵循
- **错字/乱码**：→ 指令遵循
- **文字扭曲/残缺/重影**：→ 视觉效果
- **文字颜色/大小/粗细不对**：prompt 有要求 → 指令遵循；无要求 → 不判错
- **排版位置不对**：prompt 有要求 → 指令遵循；无要求但混乱 → 视觉效果-设计感

### 拉伸与比例
- 明显拉伸/压缩导致形变 → 视觉效果
- prompt 明确要求画幅比例未满足 → 同时属于指令遵循（分别说明）

### 水印
- 被去除通常可接受
- prompt 明确要求保留但被去除 → 指令遵循

### 色调/亮度/对比度
- 编辑任务中未被要求改变却明显变化 → 一致性
- prompt 要求调整但未完成 → 指令遵循

---

## 禁止事项

- ❌ 先选整体再反推分维度
- ❌ 强行分胜负
- ❌ 把 prompt 保持要求当一致性
- ❌ T2I 判断一致性
- ❌ 按个人审美选边
- ❌ reason 模板化
- ❌ reason 与 GSB/标签矛盾
- ❌ 只写落败图问题不写胜出图问题

## 输出示例

```
指令遵循：图1完成"皮克斯动画风格女孩领奖"核心要求，但"三好学生奖状"文字模糊不清；图2同样完成核心要求，奖状文字清晰可辨。两图均完成数量和场景要求。
一致性：不涉及（T2I）。
视觉效果：图1人物手部有轻微结构问题（手指粘连），画质略偏暗；图2整体画质清晰，人物结构正常。
综合判断：两图核心指令均完成，图2文字清晰度优于图1且无结构问题，因此图片2更好。
```
