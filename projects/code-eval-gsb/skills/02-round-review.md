# GSB 轮次评价 · 追问提示词生成

> 配置从 `../config.toml` 读取。
> 依赖 agent：`skills/implementation-reviewer/SKILL.md`、`skills/humanizer-zh/SKILL.md`

每轮模型对话结束后执行本技能。判断本轮回答质量，决定满意/不满意，不满意时生成下一轮追问提示词。

## 功能概述

1. 读取本轮对话内容（模型回答）
2. 调用 `implementation-reviewer` agent 评估本轮回答质量
3. 判断是否需要继续追问：
   - **满意** → 写入轮次评价，标记本轮通过，流程结束
   - **不满意** → 写入轮次评价 + 生成下一轮追问提示词，追加到对话内容文件
4. 将评价内容追加到 `-评价结果.md`

**本技能不负责：**

- 替代用户在 Trae 中执行对话
- 自动提交最终评价汇总表单

## 命令

| 命令 | 说明 |
|------|------|
| review | 默认命令。分析指定模型的本轮对话，输出评价 + 追问决策 |

## 默认配置

> 从 `../config.toml` 的 `[review]`/`[[models]]`/`[paths]` 段读取。关键：最大 3 轮追问（含首轮）、模型名从 `[[models]]` 的 slug 读取、文件前缀 `A-`。

## 执行流程

### review（默认命令）

**输入：**
```
项目名：<项目名>
类型：<类型>
模型：<模型名>
轮次：<1 / 2 / 3>
```

**步骤：**

1. **读取本轮对话内容**：从 `-对话内容.md` 中提取：
   - 本轮用户提示词（「用户第 N 次提示词」字段）
   - 本轮模型回答（「模型第 N 次回答内容」字段）
   - 本轮 session id

2. **调用 `implementation-reviewer` agent**：传入以下上下文：
   - 首轮提示词（含约束标签，作为参照基准）
   - 本轮用户提示词
   - 本轮模型回答内容
   - 已有轮次（判断对话走向）
   - 任务类型

   分析输出：
   - 本轮回答是否准确、完整、符合约束
   - 满意度判断：**满意 / 不满意**
   - 若不满意：指出具体不足（最多 2 点）及追问方向

3. ⚠️ **必须调用 `humanizer-zh` agent**：处理满意度判断理由、不足描述、追问提示词（若需要）。humanizer-zh 是必须步骤，不可跳过。

4. **生成追问提示词（满意度为"不满意"且未达最大轮次时）**：
   - 追问提示词应针对本轮的具体不足，自然口语化，像真实用户的跟进追问
   - 不重复首轮已问过的内容
   - 若已达第 3 轮，不生成追问，提示用户本轮为最后一轮

5. **追加评价到 `-评价结果.md`**：在对应轮次区块中填入：
   - 满意度：满意 / 不满意
   - 不足描述（不满意时）
   - 追问方向（不满意时）

6. **将追问提示词写入 `-对话内容.md`**（仅不满意时）：
   - 写入「用户第 N+1 次提示词」字段
   - 若该字段已有内容，**不覆盖**，提示用户手动确认

7. 输出操作摘要，提示用户下一步。

## 路径规则

```
# 读取 + 写入追问提示词
{work_root}/{session}/ai-model-result/<项目名>/<项目名>-<类型>/A-<项目名>-<类型>-<模型名>-对话内容.md

# 追加评价内容
{work_root}/{session}/ai-model-result/<项目名>/<项目名>-<类型>/A-<项目名>-<类型>-<模型名>-评价结果.md
```

## 追加内容格式

每次 review 执行后，向 `-评价结果.md` 对应轮次区块追加：

```markdown
## 第 <N> 轮评价

满意度：<满意 / 不满意>

不足描述：<具体不足，满意时留空>

追问方向：<追问切入点，满意时留空>

评价备注：<综合评语>
```

若该区块已存在内容，**不覆盖**，在末尾追加并加分隔线 `---`。

## 对话内容文件追问写入格式

当不满意且需要追问时：

```markdown
用户第 <N+1> 次提示词：<humanizer-zh 优化后的追问提示词>
```

## 判断逻辑

| 条件 | 操作 |
|------|------|
| 满意，轮次 < 3 | 写评价，结束本模型本轮，等待用户决定是否继续 |
| 满意，轮次 = 3 | 写评价，提示三轮已完成 |
| 不满意，轮次 < 3 | 写评价 + 生成追问提示词，写入下一轮字段 |
| 不满意，轮次 = 3 | 写评价（标注已达最大轮次），**不生成追问** |

## 注意事项

1. 若 `-对话内容.md` 中本轮「模型回答内容」字段为空，**中止执行**并提示用户先填写模型回答。
2. 追问提示词要针对本轮具体不足，不能重复首轮问题，不能泛泛追问"能否详细说明"。
3. 各模型各自独立执行 review，互不影响。
4. 执行前先确认轮次参数，避免写入错误区块。
