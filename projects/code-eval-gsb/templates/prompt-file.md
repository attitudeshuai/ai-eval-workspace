# 对话内容文件模板（GSB 模式）

> 每个模型一份，N 份内容完全一致。文件名格式：`{项目名}-{类型}-{slug}-对话内容.md`（无 `A-` 前缀）

```markdown
{项目名}-{类型}-01

用户第一次提示词：{prompt 内容，与冒号同行不换行}

约束标签（0825 期按数量分布注入，本题实际使用 N 个）：
- {约束类型}：{具体约束内容}

注：只列本题实际注入的约束标签（0 个则不列），格式为「约束类型：内容」。

是否开启 Max：{是 / 否}（0825 期 60% 开启 Max、40% 不开启，同一任务所有横评模型必须一致；开启时对话底部应显示 X% of 1000K，若为小窗口说明 Max 未生效，需重测本题）

模型第一次回答 trae session id：

模型第一次回答内容：



用户第二次提示词：

模型第二次回答内容：



用户第三次提示词：

模型第三次回答内容：
```

## 字段说明

| 字段 | 说明 |
|------|------|
| 标识串 | `{项目名}-{类型}-01`（GSB 固定单条，固定 01） |
| 约束标签 | 0825 期按数量分布注入（0 个 5% / 1 个 10% / 2 个 35% / 3 个 35% / ≥4 个 15%），只列实际使用的 |
| 是否开启 Max | 0825 期 60% 开启 / 40% 不开启（更复杂/更长程开启）；同一任务所有横评模型一致，窗口内不可切换；开启时自检 `X% of 1000K` |
| 交互轮次 | 0825 期 ≤ 3 轮（无最低轮数）；打断后重新给指令计入轮次，工程故障不计入 |
