## 字段说明

| 字段 | 说明 |
|------|------|
| 标识串 | `{项目名}-{类型}-01`（GSB 固定单条，固定 01） |
| 约束标签 | 0731 期按数量分布注入（0 个 5% / 1 个 10% / 2 个 35% / 3 个 35% / ≥4 个 15%），只列实际使用的 |
| 是否开启 Max | 0731 期固定为「是」（1M 上下文窗口，自检 `X% of 1000K`） |
| 交互轮次 | 0731 期 3 ≤ 轮次 ≤ 6，题目设计需保证至少 3 轮 |
| 是否触发自动压缩 | 过程中任一轮发生压缩即选「是」；选「是」时 context 占用必须补记压缩前读数 |
| 最后一轮 context 占用 | 统一格式：未压缩 `X% of YK`；触发压缩 `X% of YK，触发自动压缩时 Z% of YK` |
