## 四、独立阅读：跨轮次与前后对比（红线）

每条数据都要能**单独读懂**，读者不需要知道前面几轮或改之前是什么样。

- **跨轮次（`CROSS_ROUND`，error）**：上一轮、前一轮、上轮、上一次轮、之前的轮次、前面几轮、本轮之前
- **与改动前对比（`PAST_COMPARE`，error）**：改动前、修改前、比之前、之前还、上一版、此前、原来、原先、原本、本来

改写方向：直接陈述现象与现状。「正确选项不再高亮」（不写「比改动前退了一步」）、「副本里多余的依赖目录已清掉」（不写「上一轮留下的依赖目录已清掉」）。

## 五、句式与结构层（不进机器表，改写时对照）

中文 AI 味最稳的几个指纹：

1. **三件套排比**：是 A、是 B，更是 C；既要 A，也要 B，还要 C；为了 A，为了 B，也为了 C
2. **「不是 X，而是 Y」连用**（一篇两次以上就要警惕）
3. **名词化**：对流程进行了优化 → 改了流程；使效率得到提升 → 跑得更快
4. **抽象主语**：时代／科技／行业／未来做主语，看不见是谁干的
5. **每段等长、每段挂小标题**：段落长度方差小是隐性指纹
6. **段尾金句升华**：这，就是……的力量／唯有……方能……
7. **虚假让步三拍**：诚然……但是……；既要看到……也要看到……
8. **最后一句复述前文**：综上所述把前文再说一遍

## 六、标点与排版层

`——`（破折号，密度最刺眼的一个）、反引号、`「」`、`→` / `⇒` / `=>` / `->`、英文直引号，这几类由 `HUMANIZER_SYMBOLS` 机器拦（error）。另外人工改写时还要注意：`【】` 段头、emoji 引导、满屏加粗、段落分割线、`oaicite` / `turn0search0` / `[cite: 1]` 这类机器 token、半角逗号混中文。
