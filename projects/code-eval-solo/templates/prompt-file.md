## 字段说明

| 字段 | 说明 |
|------|------|
| 标识串 | 第一行，格式 `{项目名}-{类型}-{index}`，文件内唯一标识 |
| 用户第N次提示词 | 发给模型的 prompt，与冒号同行 |
| 模型第N次回答 trae session id | 用户在 Trae 中对话后填写 |
| 修改范围 | 用户根据 Trae 修改记录选择 |
| 模型第N次回答内容 | 用户从 Trae 粘贴模型完整回答 |

## 注意事项

- 提示词必须使用纯自然语言，禁止出现具体 API 路径、字段名、文件名
- 文件内容禁止出现反引号（`）
- 标识串格式为 `{项目名}-{ALIAS}-{index}`
