# 标注规范

本规范面向参与 Web Dev 长程任务生产与评估的标注员/Agent。

---

## 1. 任务设计原则

### 1.1 必须迫使 agent 进入闭环

合格难题应迫使 agent 经历：

```text
理解需求 → 修改工程 → 运行页面 → 截图观察 → 发现问题 → 修复 → 再验证
```

如果 agent 无需运行浏览器即可完成任务，则难度不足。

### 1.2 多状态验收

每个任务必须覆盖至少 4 类关键状态，例如：

- 加载态 / 空态 / 错误态 / 完成态
- hover / focus / active 态
- 编辑态 / 只读态
- 移动端 / 平板 / 桌面端
- 无权限 / 有权限

### 1.3 视觉输入必须具体

禁止使用模糊描述如“高级、现代、美观”。必须提供：

- 参考截图（桌面端 + 移动端）
- 关键交互状态截图
- 颜色、字体、间距、圆角、阴影等可量化说明
- 动效参数（duration、easing、transform）

---

## 2. 需求撰写规范

### 2.1 task.md 结构

```markdown
# 任务标题

## 背景与目标

## 功能要求

### 模块 A

### 模块 B

## 交互要求

## 视觉要求

## 约束条件

## 交付标准

## 参考资料
```

### 2.2 需求必须可验收

每条需求都应能对应到至少一个 Rubric 叶节点或测试用例。

**反例：**

> 页面要看起来专业。

**正例：**

> 顶部导航在桌面端固定显示，在移动端折叠为汉堡菜单；展开/收起动画时长 300ms，使用 ease-out。

---

## 3. Rubric 设计规范

### 3.1 叶节点结构

```json
{
  "id": "r001",
  "dimension": "功能完整性",
  "criterion": "用户可以通过搜索框输入关键词并看到过滤后的结果列表",
  "weight": 0.08,
  "grader_spec": "playwright_assertion",
  "evidence_required": [
    "tests/playwright.spec.ts#L30",
    "screenshots/search_results_desktop.png"
  ],
  "notes": "需验证输入为空时显示空态，输入无结果时显示无结果提示"
}
```

### 3.2 禁止低价值叶节点

以下叶节点不允许单独出现：

- 页面能打开
- 按钮存在
- 项目能启动
- 代码没有语法错误

### 3.3 权重分配建议

| 维度 | 建议权重范围 |
|---|---|
| 功能完整性 | 25-35% |
| 交互完整性 | 20-30% |
| 视觉完成度 | 15-25% |
| 工程质量 | 10-20% |
| 边界状态 | 10-15% |
| 测试与证据 | 5-10% |

---

## 4. 视觉参考规范

### 4.1 截图要求

- `reference_desktop.png`：桌面端完整页面
- `reference_mobile.png`：移动端完整页面
- `interaction_state.png`：关键交互状态（hover、弹窗、展开等）
- `empty_state.png`：空态/错误态

### 4.2 参考说明

在 `task.md` 的“视觉要求”中说明：

- 哪些部分要求高保真还原
- 哪些部分只需风格对齐
- 哪些元素可以替换（如图标、图片）

---

## 5. 工程约束规范

### 5.1 技术栈

优先使用：

- React 18+ / Vue 3+
- TypeScript
- Vite
- Tailwind CSS / CSS Modules
- Playwright

### 5.2 禁止行为

- 不允许要求 agent 使用个人账号或外部登录
- 不允许依赖付费 API 或不可控实时数据
- 不允许依赖特定操作系统或浏览器插件
- 不允许使用已废弃或极小众的库

---

## 6. 评估规范

### 6.1 评估员准则

- 优先使用自动化证据（Playwright、DOM 断言、截图对比）。
- 无法自动化的部分使用 LLM judge 或人工 review。
- 每个评分必须有证据引用。
- 不因为 agent 未实现非需求功能而扣分。

### 6.2 失败模式记录

在评估报告中记录 agent 的典型失败：

- 未理解需求导致方向错误
- 视觉还原不到位
- 未处理边界状态
- 未运行测试/未观察页面
- 多次修复同一问题

---

## 7. 隐私与合规

- 任务内容、Rubric、参考截图、SOTA 轨迹保持私有。
- 不得公开发布或允许搜索引擎索引。
- 参考竞品截图时，抽象其布局、交互和视觉语言，不照搬品牌资产。
