
# 项目素材 / Assets

本目录用于集中管理项目所需的全部设计、参考与说明类素材，便于任务协作与后续维护。

## 项目说明

- `project-readme.md` — 项目根目录 `README.md` 的副本，包含项目背景、技术栈、功能介绍等

## 目录结构

```
assets/
├── README.md         # 本文件
├── project-readme.md # 项目 README 副本
├── screenshots/      # 页面运行截图
├── reference/        # 参考图与设计参考
├── icons/            # 图标说明与引用
├── fonts/            # 字体说明与引用
└── images/           # 图片资源说明
```

## 各目录说明

### [screenshots/](screenshots/screenshots.md)

存放项目各核心页面的运行截图，用于效果展示、需求核对或文档插图。

当前包含：

- `01-login.png` — 登录页
- `02-dashboard.png` — 仪表盘
- `03-rooms.png` — 客房状态看板
- `04-bookings.png` — 预订列表
- `05-booking-new.png` — 新建预订
- `06-booking-detail.png` — 预订详情

### [reference/](reference/design-reference.md)

用于放置设计参考图、竞品截图、风格参考、配色参考等外部参考资料。

当前包含：

- `design-reference.md` — 本项目完整的设计参考文档，包括项目概述、色彩系统、字体系统、组件风格与布局原则

### [icons/](icons/icons.md)

存放项目图标资源的说明与引用副本。

当前包含：

- `favicon.svg` — 站点图标（引用自 `public/favicon.svg`）

### [fonts/](fonts/fonts.md)

存放字体方案说明文档。

当前包含：

- `fonts.md` — 本项目使用的 Google Fonts 字体方案、加载方式与使用场景

### [images/](images/images.md)

存放项目图片资源的说明与引用副本。

当前包含：

- `react.svg` — React 图标（引用自 `src/assets/react.svg`）
