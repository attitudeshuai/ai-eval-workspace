# 项目素材 / Assets

> **AI 设计资源包**：本目录汇总了本项目的全部设计资产、参考截图与风格说明，**供其他 AI 模型生成新页面、新组件或新功能时参考**。目标是在不翻阅源码的情况下，让其他模型能够复刻本项目的视觉风格与交互模式。

## 本资源包用途

当你需要基于本项目生成新的酒店管理系统页面或功能时，请先阅读本目录下的材料，确保输出在以下方面与现有项目保持一致：

- 色彩系统（金色奢华深色主题）
- 字体系统（Cinzel / Cormorant Garamond / Inter）
- 组件风格（按钮、卡片、表单、标签、对话框等）
- 图标使用规范（MUI Icons + Lucide React）
- 页面布局与间距

## 风格约束（生成时必须遵守）

为了保持项目一致性，生成新内容时请遵守以下约束：

- ✅ 保持**金色奢华深色主题**，不要切换为浅色模式
- ✅ 标题、按钮文字优先使用 **Cinzel** 字体
- ✅ 正文、表单、数据优先使用 **Inter** 字体
- ✅ 主按钮使用金色渐变背景 + 深色文字
- ✅ 卡片使用深色渐变背景 + 金色边框
- ✅ 图标统一使用 MUI Icons 或 Lucide React
- ❌ 不要引入新的字体
- ❌ 不要使用与金色主题冲突的鲜艳色彩
- ❌ 不要改变现有的组件圆角、阴影风格
- ❌ 不要使用未经验证的外部图片链接

## 生成建议

当你基于本资源包生成新内容时，建议：

1. 先确定新页面/功能所属的业务模块（登录、客房、预订、入住、退房等）。
2. 参考 [screenshots/](screenshots/screenshots.md) 中相似页面的布局与信息结构。
3. 从 [reference/design-reference.md](reference/design-reference.md) 中复制对应的色彩、字体、组件代码片段。
4. 使用 [icons/icons.md](icons/icons.md) 中列出的图标库选择合适的图标。
5. 生成完成后，对照“风格约束”检查一致性。
