# 复杂 O2O 服务聚合平台

## 背景与目标

你正在为一个本地生活服务平台开发前端应用。用户可以在地图上查看附近商家，按分类和评分筛选，查看商家详情，规划路线，并将商品加入购物车后下单。平台需要同时支持桌面端和移动端，视觉要求参考提供的设计稿截图。

你的目标是从已有的半成品项目出发，完成剩余的核心模块，确保功能完整、视觉还原、交互流畅，并通过 Playwright 测试验证关键状态。

## 功能要求

### 模块 A：地图与商家列表联动

- 页面左侧（桌面端）/ 顶部（移动端）显示可交互地图，地图上标注商家 marker。
- 地图下方或右侧显示商家卡片列表，列表与地图联动：
  - 点击 marker，对应卡片滚动到可视区域并高亮。
  - 点击卡片，地图居中到对应 marker 并弹出信息窗。
- 商家列表支持按分类（餐饮、零售、服务、娱乐）筛选。
- 商家列表支持按评分、距离、销量排序。

### 模块 B：商家详情与路线规划

- 点击商家卡片或 marker 信息窗，进入商家详情页（路由切换，不要弹窗）。
- 详情页展示：商家头图、名称、评分、地址、营业时间、商品列表、用户评价。
- 提供“规划路线”按钮，调用浏览器 Geolocation API 获取用户当前位置（需处理拒绝授权情况），在地图上绘制路线示意（可用直线或折线示意，不强制接入真实地图 Directions API）。

### 模块 C：购物车与下单

- 商家详情页中，商品支持“加入购物车”。
- 购物车以侧边栏（桌面端）/ 底部抽屉（移动端）形式展示。
- 购物车显示商品列表、数量调整、总价计算。
- 点击“提交订单”进入下单结果页，显示成功状态与订单号。

## 交互要求

- 地图支持鼠标滚轮缩放、拖拽平移；移动端支持双指缩放。
- 筛选和排序切换时，列表和地图实时更新，并显示加载骨架屏。
- 商家卡片 hover 时显示阴影和轻微上浮动画（transform: translateY(-4px)，duration 200ms，ease-out）。
- 移动端汉堡菜单可展开/收起，动画时长 300ms。
- 购物车打开/关闭有滑入滑出动画。
- 错误处理：Geolocation 拒绝、无商家结果、网络错误均需有明确 UI 反馈。

### 设计规范

- 主色：`#1677FF`
- 背景色：`#F5F7FA`
- 卡片背景：`#FFFFFF`
- 文字主色：`#1F2937`
- 文字次色：`#6B7280`
- 字体：`system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`
- 页面最大宽度：1440px，居中
- 桌面端地图高度：calc(100vh - 80px)
- 卡片圆角：12px，阴影：`0 2px 8px rgba(0,0,0,0.08)`
- hover 阴影：`0 8px 24px rgba(0,0,0,0.12)`

## 约束条件

- 技术栈：React 18 + TypeScript + Vite + Tailwind CSS
- 必须使用 React Router 管理页面路由
- 必须使用 Context 或 Zustand 管理全局购物车状态
- 地图使用 Leaflet（已通过 starter 安装）
- 禁止使用真实后端 API，所有数据来自 `mock-data/`
- 禁止引入新的 UI 组件库（如 Ant Design、Material UI）
- Node.js >= 18，使用 npm
